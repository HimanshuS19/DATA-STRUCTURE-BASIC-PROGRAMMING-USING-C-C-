# 🚀 Getting Started

Follow these steps to set up and run the programs on your local machine.

---

## 📥 Clone the Repository

```bash
git clone https://github.com/HimanshuS19/Data-Structure-Basic-Programming-Using-C-Cpp.git
```

Move into the project directory.

```bash
cd Data-Structure-Basic-Programming-Using-C-Cpp
```

---

# 🖥 Software Requirements

Before running the programs, ensure you have:

- Visual Studio Code
- GCC Compiler
- G++ Compiler
- Windows / Linux / macOS

Recommended Extensions

- C/C++
- Code Runner

---

# ⚙ Compile & Run

## Compile C Program

```bash
gcc filename.c -o program
```

Run

```bash
./program
```

---

## Compile C++ Program

```bash
g++ filename.cpp -o program
```

Run

```bash
./program
```
